# Nutrition math

## BMR (Mifflin-St Jeor), kg and cm
- Men: `10 x weight + 6.25 x height - 5 x age + 5`
- Women: `10 x weight + 6.25 x height - 5 x age - 161`
Convert: lb / 2.2046 = kg. in x 2.54 = cm.

## Activity multiplier (TDEE = BMR x factor)
| Level | Description | Factor |
|---|---|---|
| Sedentary | desk job, < 5k steps, no training | 1.2 |
| Light | 1-3 sessions/week or 5-8k steps | 1.375 |
| Moderate | 3-5 sessions/week, 8-10k steps | 1.55 |
| Very active | 6-7 sessions/week or physical job | 1.725 |

## Goal adjustment
- Fat loss: TDEE - 15 to 25% (cap at about -500 kcal for most people)
- Maintenance / recomposition: TDEE
- Muscle gain: TDEE + 5 to 10% (about +200 to +300 kcal)

## Macros
1. Protein: 1.6-2.2 g per kg bodyweight (use goal weight if BMI > 30). Default 1.8 g/kg; 2.0-2.2 in a deficit.
2. Fat: 0.6-1.0 g per kg, and at least 20% of calories.
3. Carbs: remaining calories / 4.
Energy: protein 4 kcal/g, carbs 4 kcal/g, fat 9 kcal/g.

## Worked example
Woman, 30 y, 165 cm, 68 kg, 4 sessions/week, fat loss.
- BMR = 680 + 1031 - 150 - 161 = 1400
- TDEE = 1400 x 1.55 = 2170
- Target = 2170 x 0.8 ≈ 1740 kcal
- Protein 2.0 x 68 = 136 g (544 kcal); fat 0.8 x 68 = 54 g (486 kcal); carbs (1740 - 1030) / 4 ≈ 178 g
