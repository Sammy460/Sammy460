# Verkaufsseite für Dienstleistungen

Eine einfache Webseite, auf der Kunden deine Angebote auswählen und dir eine Anfrage per E-Mail schicken.
Kein Server, keine Datenbank, keine Kosten – nur eine Datei: `index.html`.

## Anpassen

Öffne `index.html` und ändere den Block `SHOP` (oben im `<script>`-Teil):

- `title` und `tagline`: Name und Slogan deines Angebots
- `email`: **deine echte E-Mail-Adresse** – dorthin kommen die Anfragen
- `products`: deine Angebote mit Name, Beschreibung und Preis in Euro

## Ansehen

`index.html` im Browser öffnen (Doppelklick).

## Kostenlos online stellen (GitHub Pages)

1. Im Repository auf GitHub: **Settings → Pages**
2. Unter *Source*: **Deploy from a branch**, Branch wählen, Ordner `/ (root)`
3. Speichern. Nach ca. 1 Minute ist die Seite unter `https://<dein-name>.github.io/<repo>/` erreichbar.
4. Den Link an Nachbarn, Familie oder in WhatsApp-Gruppen schicken.

## Hinweise

- Die Seite nimmt **kein Geld** an. Bezahlt wird bar oder per Überweisung, nachdem du den Auftrag erledigt hast.
- Bist du unter 18, frag deine Eltern, bevor du Angebote veröffentlichst.
- Wer regelmäßig Geld verdient, muss eventuell ein Gewerbe anmelden oder Steuern beachten.
